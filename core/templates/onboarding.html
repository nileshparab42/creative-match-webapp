GA4 audience push credentials
These are needed to push scored audiences back into GA4 via Measurement Protocol so campaigns can target them.
GA4 → Admin → Data Streams → your stream → Measurement ID
GA4 → Admin → Data Streams → your stream → Measurement Protocol API secrets → Create
How it works: After the model scores each user, their score is sent to GA4 as a custom event via Measurement Protocol. GA4 then builds audiences from these scores which get synced to Google Ads automatically.
